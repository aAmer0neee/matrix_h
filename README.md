### Введение

реализация библиотеки matrix.h на языке C

#### Функции

#### Функции для работы с матрицами

| №  | Функция                                    | Описание                                                                                                                                              |
|----|--------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1  | `int s21_create_matrix(int rows, int columns, matrix_t *result)` | Создаёт матрицу с заданными количеством строк и столбцов.                                                                                        |
| 2  | `void s21_remove_matrix(matrix_t *A)`      | Освобождает память, занятую матрицей `A`.                                                                                                            |
| 3  | `int s21_eq_matrix(matrix_t *A, matrix_t *B)` | Сравнивает две матрицы `A` и `B` на равенство. Возвращает `SUCCESS`, если матрицы равны, и `FAILURE`, если не равны.                            |
| 4  | `int s21_sum_matrix(matrix_t *A, matrix_t *B, matrix_t *result)` | Выполняет операцию сложения матриц `A` и `B`, результат сохраняется в матрице `result`. Возвращает `SUCCESS` в случае успеха, `FAILURE` — в случае ошибки. |
| 5  | `int s21_sub_matrix(matrix_t *A, matrix_t *B, matrix_t *result)` | Выполняет операцию вычитания матриц `A` и `B`, результат сохраняется в матрице `result`. Возвращает `SUCCESS` в случае успеха, `FAILURE` — в случае ошибки. |
| 6  | `int s21_mult_number(matrix_t *A, double number, matrix_t *result)` | Умножает матрицу `A` на число `number`, результат сохраняется в матрице `result`.                                                                  |
| 7  | `int s21_mult_matrix(matrix_t *A, matrix_t *B, matrix_t *result)` | Умножает две матрицы `A` и `B`, результат сохраняется в матрице `result`.                                                                          |
| 8  | `int s21_transpose(matrix_t *A, matrix_t *result)` | Выполняет транспонирование матрицы `A`, результат сохраняется в матрице `result`.                                                                  |
| 9  | `int s21_calc_complements(matrix_t *A, matrix_t *result)` | Вычисляет миноры и матрицу алгебраических дополнений для матрицы `A`, результат сохраняется в матрице `result`.                                     |
| 10 | `int s21_determinant(matrix_t *A, double *result)` | Вычисляет определитель матрицы `A`. Возвращает `SUCCESS` в случае успеха, `FAILURE` — если матрица не квадратная или произошла ошибка.            |
| 11 | `int s21_inverse_matrix(matrix_t *A, matrix_t *result)` | Вычисляет обратную матрицу для матрицы `A`. Возвращает `SUCCESS`, если обратная матрица существует, и `FAILURE`, если определитель равен 0.       |


# Инструкция по использованию

Этот проект использует `Makefile` для управления процессом компиляции и тестирования. Для работы с проектом вам понадобятся следующие инструменты:

- Компилятор `gcc`

  `sudo apt install gcc`

- Утилита `lcov` для покрытия кода

  `sudo apt install lcov`

- Библиотеки `check`, `subunit` для тестирования

  `sudo apt install check` `sudo apt install libsubunit-dev`

- Чтобы собрать проект и скомпилировать все исходные файлы в статическую библиотеку, выполните следующую команду:

  `make all`

- Запуск тестов:

  `make test`

- Покрытие кода:

  `make gcov_report`
